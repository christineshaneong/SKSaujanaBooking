1️⃣ Prerequisites

Git installed (https://git-scm.com
)

Eclipse / STS installed

Java JDK installed

2️⃣ Clone the Repository

Mac:

cd ~/Documents
git clone https://github.com/<username>/SKSaujanaBooking.git


Windows:

cd C:\Users\<YourName>\Documents
git clone https://github.com/<username>/SKSaujanaBooking.git

3️⃣ Open in Eclipse

Eclipse → File → Import → Existing Maven Projects

Browse to cloned folder

Eclipse detects pom.xml → Finish

4️⃣ Git Workflow

Commit: Right-click project → Team → Commit

Push: Team → Push Branch ‘master’

Pull: Team → Pull (before starting work)

Eclipse recognizes Git automatically. .git folder is hidden — do not delete it.

5️⃣ Notes

Project folder can be anywhere; just import in Eclipse

Default branch: master (or main if updated)

Collaborate: Pull → Work → Commit → Push
